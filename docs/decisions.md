- 상태색 한 벌: 관리 화면 `ok`·`warn`과 휴대폰 `status-*`가 같은 값을 쓴다 (초록 #2E7D4F/#EAF5EE, 주황 #A6650A/#FDF3E1, 결석 = brand/brand-tint). `status-*`는 이름만 남기고 값은 `ok`·`warn`·`brand`를 가리킨다
- 선생님 홈 위쪽 숫자: 0이면 회색(ink 50%), 1 이상일 때만 상태색
- 시간 입력은 24시간제 시·분 선택칸(`TimeSelect`). 브라우저 기본 시간 칸은 휴대폰 설정에 따라 "오후 02:30"으로 보여서 쓰지 않는다
- 키패드 상단: 버건디 바 → 흰 바탕 + 로고 (다른 화면의 흰 메뉴와 통일). 휴대폰 세로에서는 학원 이름을 숨기고 "출결"만
- 하지 않음: 회색 두 벌(관리 bg/line/sub · 휴대폰 mpage/border/hint) 정리, 재원생 목록 결과 수 위치

## 2026-10-05 출결 키패드 4자리 고정 (범준님)
- 출결 번호는 **4자리 고정** (9/29 "4~6자리" → 변경). 번호 칸 4개, **[확인] 버튼 없음**: 4번째 숫자를 누르면 바로 처리 (있는 번호면 등원·하원, 없는 번호면 "등록되지 않은 번호")
- 숫자 패드 맨 아래 줄은 0(두 칸 너비) + 지우기
- 휴대폰 뒷 4자리가 겹치면 원장님이 **다른 4자리**를 지정 (5자리로 늘리지 않음). 학생 정보 수정 창도 4자리만 받는다
- 에듀OK 번호 중 4자리가 아닌 것이 있는지 원장님께 확인 필요 (이관 전 4자리로 다시 지정) → requirements.md 4번 질문 10
- 처리 효과: 성공은 도-미-솔 차임 + 체크가 그려지고 원이 퍼짐, 실패는 낮은 삐-삐 + 좌우로 흔들림. 저가 태블릿이라 크기·투명도만 움직이고, 움직임 줄이기 설정이면 끈다
- 시연용 예시 번호 1234 = 가상 학생 조나윤 (가상 데이터에서만). 쌍둥이 동생 등 겹치는 번호는 가상 데이터에서 9xxx로 지정
- (같은 날 추가) 출결 완료 반응은 토스 송금 완료 화면처럼: 등원·하원은 **전체 화면**(체크 원 튕김 + 체크 그리기 + 글자 차례로, 2.5초 뒤 자동 복귀·누르면 닫힘), 실패·이미 처리는 입력 칸 자리에서 짧게. 키패드 문구는 **해요체**("등원했어요"), 하원 인사 "오늘도 수고했어요, 조심히 가요" (범준님: 추천안대로)
- (같은 날 추가) 설계서에는 "결과 화면에서 숫자를 누르면 그 숫자부터 바로 입력"이라고 했지만, 전체 화면이 숫자 패드를 덮어 터치로는 숫자를 누를 수 없어서 **화면을 누르면 바로 닫힘**으로 바꿨다. 연결된 키보드로 숫자를 치면 그 숫자부터 입력된다
- (같은 날 참고) 예시 번호 1234(조나윤)는 수·금 수업이라 월요일 시연에서는 등원 화면에 "오늘 수업" 줄 없이 시각만 보인다. 수업 줄을 보여 주려면 그날 수업이 있는 학생 번호로 시연
