# 화면 명세 (v0.1, 2026-09-30)

- 목적: 2단계부터 이 문서대로 구현한다. 화면마다 **구성 · 동작 · 권한 · 요구사항 ID · 상태**를 적는다
- 디자인 기준: `/design` 스타일 가이드, `CLAUDE.md` 디자인 규칙, 공통 부품 `src/components/ui/`
- 시연: 가상 데이터로 동작한다. `?at=HH:MM`으로 시각을 바꿔 볼 수 있다
- 상태 표기: ✅ 화면 완성(가상 데이터) · 🟡 일부 · ⏳ 미작성

## 공통

### 상단 메뉴 (원장님·선생님) ✅
- 3단 구조 (에듀OK 방식): ① 로고 · 사용자 · 로그아웃 ② 버건디 주 메뉴 (PC 가운데 정렬, 칸 너비 같음) ③ 하위 메뉴 (있을 때만)
- 휴대폰: 메뉴 줄을 옆으로 밀어서 본다
- 메뉴 정의: `src/lib/nav.ts` (원장님 7개, 선생님 6개). 아직 없는 화면은 "준비 중"
- 요구사항: HOME-01

### 모바일 앱 틀 (학생·학부모) ✅
- 상단: 로고 · 이름 / 하단 탭 4개 (홈 · 숙제 · 출결 · 메시지) / 본문 폭 최대 560px

- Esc, 바깥 누르기, × 로 닫힘. 열려 있는 동안 뒤 화면 스크롤 잠금

## 로그인 `/login` ✅
- 구성: 흰 화면에 로고(앱 상단과 같은 모양) → 안내 문장 "학원에서 받은 계정으로 로그인해 주세요" → 입력칸 → [로그인] → 카카오톡 문의. PC는 가운데, 휴대폰은 위에서부터. 10/1 범준님: 왼쪽 소개 패널·카드 상자 없이 부드럽게
- 입력칸: 테두리 없이 연한 바탕, 누르면 버건디 테두리. 비밀번호 [보기] 버튼
- 입력: 아이디(휴대폰 번호 또는 학원이 정한 아이디), 비밀번호, 로그인 상태 유지 / [로그인] / 카카오톡 문의
- 동작(2단계): 로그인 → 역할별 첫 화면 (원장님 `/admin`, 선생님 `/teacher`, 학생 `/student`, 학부모 `/parent`, 키패드 `/kiosk`). 첫 로그인이면 비밀번호 변경 화면으로
- 오류: "아이디 또는 비밀번호가 맞지 않습니다" (어느 쪽이 틀렸는지 말하지 않음). 비활성 계정은 "사용이 중지된 계정입니다. 학원에 문의해 주세요"
- 요구사항: AUTH-01~08

## 선생님 첫 화면 · 출결 현황 `/teacher` ✅
- 권한: 선생님(담당 반 학생만), 원장님은 같은 구성으로 전체 학생 (`/admin/attendance`에 재사용)
- 위: 날짜(‹ 오늘 ›) · 요약 숫자 (오늘 수업, 등원, 미등원, 결석)
- 필터: 반(인원 수) / 상태(전체·미등원·등원·하원·결석) / 이름 검색
- 색 안내: 등원 초록 · 하원 파랑 · 미등원 주황 · 결석 빨강 · 수업 전 회색
- 목록 3구역: **오늘 등원** / **오늘 수업 · 등원 전** / **오늘 수업 없음**
- 학생 타일: 체크박스 · 이름(누르면 상세) · 학교·학년 / 오늘 수업 시간 · 상태 / 등원·하원 시각 · [출결] / 비고
- 여러 명 선택 시 하단 줄: [등원 처리] [하원 처리] [메시지 보내기] [선택 해제]
- 미등원 계산: 오늘 수업이 있고, 시작 시간이 지났고, 등원 기록이 없으면 미등원 (저장하지 않고 계산)
- 바로 열기: `/teacher?student=s010` (상세), `&mode=attendance` (출결 입력) → 알림에서 연결할 때 사용
- 요구사항: HOME-03~05, HOME-07, HOME-11, ATT-01, ATT-04, ATT-05

### 학생 상세 패널 ✅
- 제목: 이름 / 학교·학년·반
- 탭 없이 한 화면 (10/1 결정), 위에서부터:
  - 오늘 출결 요약 + [출결 입력]
  - 수업 정보: 학교·학년, 반, 수업 시간(요일별), 출결 코드, 사용 프로그램(선생님이 체크·저장), 보호자(이름·전화), 메모
  - 최근 2주 출결, 보강 일정
  - 최근 숙제 5개(일반/매일 · 제목 · 날짜 · 제출/미제출), [더보기 →] 숙제 화면 / **이 학생에게 숙제 등록** (대상 선택 없음: 일반·매일, 제목, 오늘 날짜 사용, 내용)
- 메시지: [학부모] [학생] 대화방 전환 (9/30 결정: 학생 대화방 분리) / 대화 목록(상대 왼쪽, 학원 오른쪽) / 입력칸 + [예약 발송] 체크 시 시각 선택 + [보내기]/[예약하기]
- 요구사항: HOME-06, HW-01, HW-02, MSG-02, MSG-04, MSG-05

### 출결 입력 창 ✅
- 상태: 정상 · 결석 · 미등원 (결석이면 시간 입력 잠김)
- 등원: 체크 + 시(08~22) + 분(5분 단위) + [현재시간] / 하원: 같음
- 비고 / [출결 등록] [취소]
- 저장하면 타일이 바로 바뀐다 (지금은 화면에서만, 3단계에서 서버 저장 · method = manual)
- 요구사항: ATT-02, ATT-03, KIOSK-07

## 출결 키패드 `/kiosk` ✅
- 태블릿 가로: 왼쪽 표시·안내 / 오른쪽 숫자 패드. 세로·휴대폰: 위아래
- 위: 학원 로고 · 날짜 · 현재 시각
- 숫자 패드 (1~9, 지우기, 0, 확인). 누르는 칸 높이 80px 이상
- 동작: 코드 입력 → 학생이 한 명만 정해지고 앞자리가 같은 더 긴 번호가 없으면 바로 처리, 6자리가 차도 바로 처리, 그 밖에는 [확인] → 오늘 첫 입력 등원 / 두 번째 하원 / 세 번째부터 "이미 하원" / 없는 코드 안내 / 1분 안에 같은 코드 다시 누르면 "방금 처리"
- 결과를 크게 4초 보여 준 뒤 처음으로. 키보드 숫자·Enter·Backspace도 됨
- 보안: 키패드 계정은 서버 함수 `kiosk_check(code)`만 호출. 학생 명단을 화면에 내려받지 않는다 (지금은 시연용으로 코드·이름만 내려받음)
- 요구사항: KIOSK-01~08
