## 1. 사용자 역할

| 역할 | 코드 | 설명 |
|---|---|---|
| 총괄관리자 | `admin` | 원장님. 모든 데이터와 기능 |
| 선생님 | `teacher` | 담당 반 학생만 |
| 키패드 | `kiosk` | 학원 입구 태블릿. 출결 코드 입력만 가능 (KIOSK) |
| 학생 | `student` | 본인 데이터만 |
| 학부모 | `parent` | 연결된 자녀 데이터만. 자녀가 여러 명일 수 있음 |

- 역할별로 앱을 따로 만들지 않는다. 하나의 앱에서 로그인한 역할에 따라 메뉴와 데이터가 달라진다
- **모든 권한은 서버(DB 정책)에서 검증한다.** 화면에서 메뉴를 숨기는 것만으로 권한을 판단하지 않는다

## 2. 기능 요구사항

### AUTH. 로그인·계정
| ID | 요구사항 | |
|---|---|---|
| AUTH-01 | 학원이 발급한 계정으로만 로그인 (아이디 + 비밀번호). 회원가입 없음 | 필수 |
| AUTH-02 | 로그인 아이디는 기본적으로 휴대폰 번호. 휴대폰이 없거나 형제가 번호를 공유하는 학생은 원장님이 다른 아이디를 지정 | 필수 |
| AUTH-03 | 첫 로그인 시 비밀번호 변경 강제 | 필수 |
| AUTH-04 | 원장님이 비밀번호 재설정 (임시 비밀번호 발급 → 다음 로그인 시 변경) | 필수 |
| AUTH-05 | 계정 비활성화 (퇴원생, 퇴사 선생님). 기록은 유지 | 필수 |
| AUTH-06 | 로그인 상태 유지 체크 (앱을 닫았다 열어도 로그인 상태). **기본은 꺼짐** (공용 PC·태블릿에서 다음 사람이 그대로 로그인되지 않게, 10/1). 키패드 태블릿은 설치할 때 원장님이 한 번 체크 | 필수 |
| AUTH-07 | 로그아웃 | 필수 |
| AUTH-08 | 로그인 화면에 LEET영어학원 로고, 카카오톡 문의 링크 (자체 비밀번호 찾기는 없음: 학원 발급 계정이라 원장님이 재설정, AUTH-04) | 필수 |
| AUTH-09 | 로그인 실패 문구는 이유와 상관없이 하나: "아이디 또는 비밀번호가 올바르지 않습니다." (없는 아이디·틀린 비밀번호·사용 중지 계정을 구분하지 않음. 계정이 있는지 드러나지 않게) | 필수 |
| AUTH-10 | 로그인 시도 횟수 제한 (학생 비밀번호가 단순할 수 있어 무작정 대입 방어): 같은 아이디로 5번 연속 틀리면 10분 동안 로그인 막음, 성공하면 횟수 초기화. 같은 기기(IP)에서 짧은 시간에 많이 시도해도 막음. 막혔을 때도 AUTH-09 문구 + "잠시 후 다시 시도해 주세요" | 필수 |

### STU. 학생 관리
| ID | 요구사항 | |
|---|---|---|
| STU-01 | 학생 정보: 이름, 학생 전화(없을 수 있음), 학교, 학년, 생년월일, 재원 상태(재원·휴원·퇴원·예정), 입학일, 휴·퇴원일, 소속 반(여러 개), 출결번호, 사용 프로그램, 메모 | 필수 |
| STU-02 | 출결 코드(4~6자리): **에듀OK 번호를 그대로 옮긴다**(10/1 원장님 확인). 새 학생은 전화 뒷 4자리로 자동 설정, 원장님이 수정 가능. **재원생끼리 겹치지 않게** 등록 시 중복 경고 (실제로 뒷 4자리가 겹치는 학생이 있음) | 필수 |
| STU-03 | 사용 프로그램 복수 선택(선생님이 지정): 클래스카드, 클래스5, 오토보카. 목록 추가·수정(원장님)은 선택 | 필수 |
| STU-04 | **학생별 수업 시간표**: 요일 + 시작 시간 + 수업 시간(분). 요일마다 다를 수 있음 (예: 화 15:00 120분, 목 15:10 120분) | 필수 |
| STU-05 | 학부모 전화 입력란은 학생 화면에 두지 않는다. 학부모 계정·연결은 별도 화면(STU-07) | 필수 |
| STU-06 | 학생 목록: 반·상태 필터, 이름·학교·전화·메모 검색, 정렬 | 필수 |
| STU-07 | 보호자 관리: 보호자 이름, 관계(모·부·기타), 전화 1·2, 연결된 자녀(여러 명). 형제는 보호자 1명에 자녀 여럿으로 연결 | 필수 |
| STU-08 | 학생 로그인 계정 생성, 보호자 로그인 계정 생성 (AUTH-02) | 필수 |
| STU-09 | 휴원·퇴원 처리 시 날짜 기록, 목록에서 기본 숨김(필터로 조회 가능), 계정 비활성화 여부 선택 | 필수 |
| STU-10 | 엑셀(CSV)로 학생 일괄 등록 (에듀OK 명단 이관용). 이름에 섞인 학교·학년 분리 | 선택 |

### ATT. 출결

| ATT-06 | 모든 날짜는 **한국 시간** 기준 | 필수 |
| ATT-07 | 출결 내역 조회: 학생별·기간별 | 필수 |

| ATT-09 | 학부모 결석 신청: 날짜, 사유 → 원장님·담당 선생님에게 알림, 해당 날짜 출결에 반영 | 필수 |

### KIOSK. 출결 키패드 (학원 입구 태블릿)
| ID | 요구사항 | |
|---|---|---|
| KIOSK-01 | 태블릿 전용 화면: 큰 숫자 패드, 입력칸, 지우기·확인. 가로·세로 화면 모두 지원 | 필수 |
| KIOSK-02 | 학생이 출결 코드(주로 4자리, 4~6자리 허용)를 입력하면 오늘 첫 입력은 **등원**, 다음 입력은 **하원**으로 기록 | 필수 |

| KIOSK-07 | 잘못 찍은 기록은 선생님·원장님이 출결 화면에서 수정 (ATT-03) | 필수 |
| KIOSK-08 | 인터넷이 잠깐 끊겨도 입력을 보관했다가 다시 연결되면 전송 | 선택 |
