## 1. 누가 무엇을 쓰나

| 사용자 | 할 수 있는 것 |
|---|---|
| **원장님** | 모든 기능. 학원 현황(새 메시지·숙제 제출·오늘 보강·미등원·출결·숙제 미제출·선생님 출근), 학생·반·선생님·계정 관리, 출결·숙제·보강·메시지, 선생님 출퇴근 |
| **선생님** | 담당 반 학생만. 오늘 출결 현황, 학생 상세(수업 정보·최근 출결·숙제·메시지), 숙제 등록·피드백, 사용 프로그램 지정, 보강, 본인 출퇴근 |
| **학생** | 오늘 할 숙제 확인·제출(사진 최대 10장)·수정, 선생님 코멘트, 출결·보강 확인, 학원과 메시지(답장 가능) |
| **학부모** | 자녀 숙제·제출 상태, 등원·하원 알림, 보강 일정, 결석 신청, 학원과 메시지. 자녀가 여러 명이면 한 계정으로 모두 확인 |
| **출결 키패드** | 학원 입구 기기에서 학생이 번호를 누르면 등원·하원 기록 + 부모님 알림 |

- 선생님 이름은 학생·학부모에게 **닉네임**으로만 보입니다
- 학생과 학부모의 메시지는 **따로** 주고받습니다 (학생은 부모님과 선생님의 대화를 볼 수 없음)

## 2. 기능 목록

**출결**
- 학생이 입구 태블릿에서 번호(주로 4자리)를 누르면 첫 입력은 등원, 두 번째는 하원 (처리 소리)
- **지금 에듀OK 출결 번호를 그대로 사용** (10/1 확인)
- 선생님 화면에서 등원·하원 시각, 정상·결석·미등원, 비고를 입력·수정, [하원] 바로 처리
- 수업 시간이 지났는데 등원 기록이 없으면 자동으로 **미등원** 표시 → 원장님 현황에 표시
- 학부모: 등원·하원 알림, 결석 신청

**숙제**
- 일반 숙제·매일 숙제 구분. 매일 숙제는 **기간을 정해 매일 내는 숙제와 그날 하루 숙제 둘 다** (10/1 확인)
- 한 명·여러 명·반 전체에게 등록, "오늘 날짜" 제목
- 학생 제출: 코멘트, 사진 최대 10장(자동으로 용량 줄임), 제출 후 수정
- 선생님 피드백, 사진 크게 보기(이전/다음), 제출 현황
- 제출하면 선생님·원장님에게 알림

**학생·반·선생님 관리**
- 학생: 학교·학년, 재원·휴원·퇴원·예정, **학생별 수업 요일·시간**, 출결 번호, 사용 프로그램, 보호자(여러 명, 형제 연결), 메모
- 반: 반 이름, 담당 선생님, 수업 요일, 학생 여러 반 소속 가능
- 선생님: 실명·닉네임, 담당 반, 출퇴근 기록
- 계정: 원장님이 발급·비밀번호 재설정·사용 중지, 첫 로그인 시 비밀번호 변경

**보강 · 메시지 · 알림**
- 보강 등록·일정, 오늘 보강 현황
- 학부모·학생과 대화, 여러 명에게 보내기, **예약 발송**, 읽음 확인
- 휴대폰·PC에 **앱처럼 설치**, 알림 받기, 설치 후에도 자동 업데이트

**홈페이지 연결**
- 학원 홈페이지(leetenglish.kr)에 로그인 버튼 → 앱(app.leetenglish.kr)으로 이동
