## 1~3'. 선생님·원장님 화면 수정 (작음) — 10/5 반영 완료 (학부모 전환은 유지하고 학생 대화방을 먼저 보여 줌, 원장님 확인 필요)
- 수업 정보를 2열 표로: `반 | 수업 시간` / `출결 코드 | 사용 프로그램` / `보호자 | 메모`, 칸 사이 가는 선 (원장님이 "테이블 줄" 원함)
- 최근 2주 출결 구역 삭제 (데이터는 그대로, 학생 상세의 다른 화면에서 필요하면 다시)
- 빈 자리에 학생 대화방 미니 창: 최근 메시지 3~4개 + 입력칸. [학부모] [학생] 전환은 유지할지 원장님께 확인 (요청 문구는 "학생과")
- 원장님 홈 학생 이름: font-semibold → font-bold, 글씨색 ink

## 4. 보강 하루 전 알림
- 매일 저녁(예: 19:00) 다음 날 보강이 있는 학생의 학부모에게 푸시 알림: "내일 15:00 보강이 있습니다 (진도 보충)"
- 구현: Supabase pg_cron(또는 Vercel Cron) → 알림 함수 → Web Push. 알림 기능(NOTI) 위에 얹으므로 5단계
- 확인할 것: 보낼 시각, 학생에게도 보낼지

## 5. 성적·레포트 (새 기능)
흐름: 선생님 메모 → 월 1회 자동 초안 → 선생님 확인·수정 → [보내기] → 학부모 앱에 레포트
- 데이터: `student_notes`(학생, 선생님, 날짜, 내용), `reports`(학생, 기간, 초안, 최종본, 상태: 초안/확인/보냄, 보낸 시각)
- 권한(RLS): 메모·초안은 담당 선생님과 원장님만, 학부모는 "보냄" 상태의 최종본만, 학생은 보지 않음(원장님께 확인)
- 화면: 선생님 학생 상세에 메모 쓰기, 레포트 목록·수정·보내기 / 학부모 앱에 레포트 메뉴 / 원장님 전체 현황
- 자동 생성: 매월 1회 서버에서 GPT API 호출 (원장님 프롬프트 사용). 학생 이름·학교는 빼고 보냄(개인정보), 결과에 다시 이름을 넣음
- 필요한 것 (원장님): ① OpenAI 계정·결제 수단, API 키(원장님 명의) ② 프롬프트 ③ 레포트에 넣을 항목(출결 요약·숙제 제출률도 넣을지)
- 비용: 사용한 만큼 과금. 학생 80명 × 월 1회면 아주 적은 금액으로 예상 (정확한 금액은 모델·길이 정한 뒤 확인)
- 개인정보: 학생 메모가 외부 AI 서비스로 나감 → 학부모 안내(개인정보 처리 방침)에 한 줄 필요, 이름 제외 전송
- 일정: 5~7일. 선택지
  - A. 여유 기간(12/7~12/13)에 넣고 오픈 12/21 유지 (테스트 여유가 줄어듦)
  - B. 오픈 뒤 추가 작업으로 (1월 중)
  - 범위 확정 전 추가지만 규모가 커서 **추가 비용·일정을 협의할지 범준님이 결정** (계약: 확정 뒤 새 기능은 별도 협의)

## 6. 메시지 사진 보내기
- 숙제 제출용 사진 올리기(자동 용량 줄임, Storage 비공개 + 서명 URL)를 메시지에도 사용
- 한 번에 몇 장까지, 학생도 보낼 수 있는지 확인
- 5단계 메시지 작업에 포함

## 7. 교재비 (가벼운 버전)
- 교육비 청구·수납은 에듀OK에 그대로 두고(10/1 결정), 교재비만 메모 수준으로: 학생(또는 반)에 "교재비 OO원, 메모" 등록 → 학부모에게 푸시 → 원장님이 [입금 완료] 누르면 완료 표시
- 데이터: `material_fees`(학생, 금액, 메모, 등록일, 입금 완료 여부·시각). 권한: 원장님 전체, 학부모는 자녀 것만 보기
- 결제 기능(카드·계좌 연동)은 넣지 않는다
- 확인할 것: 선생님도 등록할 수 있는지, 반 전체에 한 번에 등록할지
- **10/5 추가 요청: "교재 내역과 함께 교재비가 잘 보였으면"** → 금액 한 줄이 아니라 교재별 내역 + 합계
  - 데이터: `material_fees`(청구 한 건: 학생, 등록일, 메모, 입금 완료 여부·시각) + `material_fee_items`(교재명, 금액, 수량). 합계는 저장하지 않고 항목에서 계산
  - 자주 쓰는 교재는 `materials`(교재명, 기본 가격)에 등록해 두고 골라 담기 → 반 전체 등록이 쉬워짐 (원장님 확인)
  - 학부모 화면: 청구 카드 하나에 교재명·금액 목록, 아래 합계를 크게, 상태(입금 전/입금 완료). 지난 청구는 아래에 접어서
  - 규모 다시 보기: 1.5~2일 → 2~2.5일 (교재 목록·내역 화면 추가)
