# 여유 작업 목록 (하루 계획이 일찍 끝났을 때)

일별 계획(`progress.md`)을 마치고 시간이 남으면 여기서 고른다. 고르는 순서: **A(요구사항인데 계획에 없는 것) → B·C(눈에 보이는 것) → D·E**.
- "가능" 열: 그날부터 할 수 있다 (앞 기능이 있어야 하는 것).
- 표시 ★: 원장님 확인이 필요하다 (화면 문구·새 동작·범위). 만들기 전에 범준님과 상의하고, 시연 때 설명한다.
- 표시 ⚠: DB 적용이나 외부 설정이 들어간다. 계획을 먼저 보여 주고, 실행은 범준님이 한다.
- 한 건 마칠 때마다 이 표에서 지우고 `progress.md` 세션 기록에 남긴다. 작업일지에는 `[작동]`이나 일반 줄로 적는다.
