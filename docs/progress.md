   - 대상: 선생님 홈(출결 현황·학생 상세·출결 입력), 원장님 홈, 재원생 목록, 출결 키패드, 학생 홈, 학부모 홈, 로그인, 스타일 가이드
   - 화면마다 볼 것: 빠진 정보, 불필요한 정보, 버튼 위치·크기, 글씨·색, 휴대폰에서 누르기 편한지, 에듀OK와 비교해 원장님이 익숙할지
   - 결정 사항은 `docs/screens.md`와 `docs/decisions.md`에 바로 반영하고, 고칠 것은 기능 단위로 수정·커밋
2. **개발 범위 확인서 PDF**: 검토를 마친 화면 캡처를 넣어 원장님께 보낼 PDF로 만들기
3. **테스트 환경 + 첫 테스트**: 한국 시간 계산, 미등원 판정
4. **DB 첫 테이블 + 보안 규칙(RLS) + 권한 테스트**, 납품 문서 "데이터베이스 구조 및 초기화 방법" 시작
